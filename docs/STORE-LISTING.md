## Description

Tessera shows exactly what fills your PC, as one clear picture, and helps
you free space safely.

Scan any drive or folder and every folder becomes a tile sized by the space
it uses, so large videos, old backups, virtual machines and forgotten
downloads stop hiding. Rank your largest files, search with filters, find
exact duplicates, and get Smart Scan suggestions that explain why each item
was found and how safe it is to remove.

Free, with no limits: scanning, the storage map, largest files, search,
Smart Scan suggestions, the duplicate finder, the list of installed apps
and Restore.

Tessera Pro, a one-time purchase inside the app, adds the actions: cleanup
to the Recycle Bin in a few clicks with Undo, freeing space from OneDrive
files while keeping them in the cloud, uninstalling apps, CSV and printable
reports, and storage history.

Private by design: scans stay on your computer. No account, no uploads, no
analytics. Tessera goes online only to check a Pro licence.

## Reason for the runFullTrust capability (if asked)

Tessera is a desktop disk space analyser. It reads file and folder sizes
across the drives the user chooses to scan, moves items the user has
reviewed to the Recycle Bin, and stores its licence in Windows Credential
Manager. It is a Win32 desktop app (built with Tauri/WebView2), so it runs
as a full-trust desktop application.
